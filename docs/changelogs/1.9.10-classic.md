# SQP_Classic v1.9.10-classic

Stable release of the Classic product line, graduating the beta port of the
Forever-validated interface and fixes while keeping the classic TOC,
`SQPClassicSettings` storage, and compatibility layers intact.

- Options rebuilt on framework cards with per-type Main Icon / Task Icon /
  Animation headers and pinned preview behavior.
- New Test Detection button in the compacted General tab.
- X/Y position sliders use the flicker-free refresh path.
- Quest progress fails closed on secret GUID contexts; quest text matching no
  longer aliases partial family names (Direwolf vs Wolf regression).
- SavedVariables ownership stays raw; old flat `SQPClassicSettings` values
  migrate into the Default profile through the framework `legacyFlat` mode.
  Percent sign defaults remain at the prior Classic baseline.
- Legacy MoP nameplate polling remains the Classic capability path; retail-only
  APIs stay behind compat checks.
- Localization: complete esMX module and key-routed UI strings.
- Packaging: in-house deterministic packager; Wago project ID corrected.
