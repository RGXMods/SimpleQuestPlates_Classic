# SQP_Classic v1.9.10-classic.beta.1

Fork beta port of the Forever-validated interface and fixes to the Classic
product line, keeping the classic TOC, `SQPClassicSettings` storage, and
compatibility layers intact.

- Options rebuild on framework cards with per-type Main Icon / Task Icon /
  Animation headers and pinned preview behavior.
- Quest progress fails closed on secret GUID contexts; quest text matching no
  longer aliases partial family names (Direwolf vs Wolf regression).
- SavedVariables ownership stays raw; **old flat SQPClassicSettings values
  migrate into the Default profile** through the framework `legacyFlat` mode.
  Percent sign defaults at the prior Classic baseline.
- Legacy MoP nameplate polling remains the Classic capability path; retail-only
  APIs stay behind compat checks.
